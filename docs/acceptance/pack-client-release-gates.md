## Bounded deployed acceptance, only after its own test-write approval

- [ ] Synthetic case is explicit, no customer record changes or external submission.
- [ ] Risk event/link/alert/review/cost reference, GEHI finding/audit, scene asset/audit, recovery finding/audit, and scenario/baseline contribution freeze in the same pack source. Missing records and unverified provenance remain visible.
- [ ] Same-port/name-only unrelated case/event is excluded from source, summary and PDF; historic moved-case before/after payloads do not leak.
- [ ] Stored scenario machine arrays do not become trusted facts; canonical case baseline comes from explicit database links; modeled-impact gaps remain visible.
- [ ] New pack canonical bytes, database hash, generation audit, version and DRAFT state agree. Old frozen pack bytes stay unchanged; no live append to historical export.
- [ ] JSON and PDF represent the same sealed source, with export-limit errors explicit and no silent integrated-register truncation.
- [ ] Actual route/imagery behavior is checked without fabricated shipment positions or causal claims. Registration is not conversion/render/alignment proof.
- [ ] No pack approval, money-recovered state, paid model call or client submission without its own approved scope.

## Still separate original product work

A working evidence-pack contribution does not establish scene conversion/model execution, analysis-grade aligned imagery, historical voice completion or a modeled scenario forecast. Record each actual result and gap before calling the entire product client-ready.
